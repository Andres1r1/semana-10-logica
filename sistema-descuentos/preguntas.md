## 1. ¿Porque utilizo if, else if y else?
Para guardar en la variable descuento el valor correspondiente segun el valor de compra ingresado.

## 2. ¿Qué ocurre si la compra es exactamente $300.000?
Al cliente se le aplicara un descuento del 20% pues pues se cumplira 'compra >= 300000'.

## 3. ¿Qué ocurre si la compra es $99.999?
No se cumplira ninguna de las condiciones para tener descuento por lo tanto sera igual a 0.

## 4. ¿Por qué es importante organizar correctamente las condiciones?
Si no se organizan bien un valor de 300.000 podria terminar con un descuento del 10% ya que se cumpliria 'compra >= 100000'.

## 5. ¿Qué función cumple Scanner?
Leer el valor ingresado por el usuario y asignarlo a una variable.

## 6. ¿Qué diferencia existe entre el valor de la compra y el total a pagar?
El valor de la compra es el valor ingresado por el usuario. El total a pagar es el valor final con el descuento aplicado.
